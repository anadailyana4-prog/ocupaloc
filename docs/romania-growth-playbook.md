# OcupaLoc Romania Growth Playbook

## Objective
Win the Romanian service-booking segment by owning:
- local category SEO intent,
- direct outbound to high-LTV businesses,
- high-trust onboarding and retention loops.

## ICP Priority (Romania)
1. Barbershops / salons with 2-10 staff in top 12 cities.
2. Clinics and therapy practices with recurring appointments.
3. Beauty and wellness operators with no-show pain.

Primary trigger conditions:
- heavy WhatsApp booking traffic,
- frequent no-shows,
- no online scheduling page,
- weak Google reviews velocity.

## Acquisition System

### A) Local SEO domination
- Build and maintain city + niche landing pages:
  - `/programari-online-[nisa]-[oras]`
- Target keywords:
  - "programari online salon [oras]"
  - "soft programari [nisa]"
  - "reducere no-show [nisa]"
- Content structure per page:
  - pain point -> measurable outcome -> product walkthrough -> local social proof -> CTA.
- Publish cadence:
  - minimum 3 high-quality pages/week.

### B) Outbound engine (ethical, permission-based)
- Use lead scoring from maps/directories.
- Run `leads:dry` weekly and manually approve before any send.
- Keep campaign sequence:
  - Touch 1: concise value email
  - Touch 2 (72h): case/outcome follow-up
  - Touch 3 (7d): breakup + trial offer
- Success KPI:
  - reply rate > 4%, demo rate > 1.5%.

### C) Trust conversion layer
- Public proof artifacts:
  - uptime/status page,
  - transparent pricing,
  - customer outcomes by niche.
- On-site conversion improvements:
  - one dominant CTA per page,
  - category-specific testimonials,
  - visible data/privacy assurances (EU/GDPR).

## Activation and Retention

### 7-day activation path
Day 0:
- business profile setup complete,
- services imported,
- booking link generated.

Day 1:
- first booking test completed.

Day 3:
- reminder automation enabled.

Day 7:
- owner receives weekly KPI digest:
  - bookings,
  - confirmation rate,
  - no-show delta.

### Retention loops
- Weekly summary email for all active tenants.
- Monthly business review mail with trend + next-step recommendation.
- Churn rescue triggers for low activity cohorts.

## Metrics Dashboard (North-star set)
- Visitor -> signup conversion
- Signup -> first booking activation
- 30-day retained businesses
- No-show reduction percentage
- Revenue per active business
- CAC payback period

## 90-Day Plan

### Phase 1 (Weeks 1-2) - Foundation
- Lock CI/CD reliability and backup success.
- Finish instrumentation for acquisition and activation funnel.
- Define city-niche page templates.

### Phase 2 (Weeks 3-6) - Acquisition burst
- Publish 20+ SEO pages.
- Start controlled outbound in 3 pilot cities.
- Install weekly experiment loop (offer, copy, CTA).

### Phase 3 (Weeks 7-12) - Scale
- Expand to 12+ cities.
- Add niche-specific onboarding flows.
- Build referral program for existing businesses.

## Non-negotiables
- Never run mass cold outreach without manual review.
- Never claim outcomes without evidence.
- Never trade security/privacy for growth speed.

## Weekly Operating Rhythm
- Monday: KPI review + issue triage.
- Tuesday: product improvements for activation.
- Wednesday-Thursday: SEO + outbound execution.
- Friday: retention experiments + postmortem.
